Titanic Dataset Analysis 🚢

📌 About the Project

This project analyzes the Titanic dataset using Python to explore passenger survival rates and identify patterns based on gender, age, and passenger class.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

📊 Key Features

- Loads and explores the Titanic dataset.
- Handles missing values in "Age" and "Embarked".
- Displays summary statistics.
- Visualizes survival counts and survival rates.
- Analyzes survival by gender, passenger class, and age.
- Creates 5 data visualizations.

📂 Dataset

Source: "Titanic Dataset – GitHub" (https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv)

▶️ How to Run

1. Install the required libraries:
   pip install pandas matplotlib seaborn
2. Save the code as "titanic_analysis.py".
3. Run the script:
   python titanic_analysis.py

🎯 Objective

To practice data cleaning, exploratory data analysis (EDA), and data visualization using Python.
